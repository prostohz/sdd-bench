# Смена приоритета существующей задачи

Я пользуюсь `./tasks` для списка дел. Приоритет сейчас можно выбрать только при добавлении задачи. Планы меняются: хочу менять приоритет уже записанной задачи, не удаляя и не создавая её заново.

Добавь команду `./tasks priority <номер> <high|normal|low>`. Номер — постоянный номер задачи, соответствующий её месту в `tasks.json`, даже если `list` показывает задачи в другом порядке или с фильтром. После успешной команды меняется только приоритет выбранной задачи; текст, отметка выполнения, теги, номер и порядок записей сохраняются. Следующий `list` и фильтр `--priority` должны сразу учитывать новое значение.

Команда должна работать и с накопленным `tasks.json`, где у задачи ещё нет поля `priority`: до изменения такая задача считается `normal`. При неверном номере, недопустимом приоритете или недостающих аргументах сообщи об ошибке в stderr, верни ненулевой код и не меняй файл.

Актуальная спецификация уже есть в проекте. Обнови её вместе с реализацией: прежний запрет на смену приоритета больше не действует. Остальные команды, данные и поведение сохрани. Правка текста, тегов и признака выполнения этой новой командой не нужна.
