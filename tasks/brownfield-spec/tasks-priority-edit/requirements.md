# Требования намерения — смена приоритета

Список для судьи `spec-fit`; участникам не показывается. Существующий контракт сохраняется и должен остаться в итоговой спецификации.

- U1. Новая команда имеет форму `./tasks priority <номер> <high|normal|low>`.
- U2. Команда принимает ровно три существующих значения приоритета: `high`, `normal`, `low`.
- U3. Номер выбирает задачу по её позиции в `tasks.json`, а не по текущему порядку или фильтру вывода.
- U4. Успешная команда сохраняет новый приоритет выбранной задачи в `tasks.json`.
- U5. Смена приоритета сохраняет текст, отметку выполнения, теги, номер и порядок всех задач.
- U6. Следующий `list` показывает задачу на месте, соответствующем новому приоритету; `list --priority` учитывает изменение.
- U7. Команда работает со старой записью без `priority`, считавшейся `normal`, без потери остальных данных.
- U8. Неверный номер, недопустимый приоритет и недостающие аргументы дают ненулевой код и сообщение в stderr.
- U9. Любая ошибка команды оставляет `tasks.json` без изменений.
- S1. Итоговая спецификация обновляет существующий контракт и больше не запрещает смену приоритета.
- K1. `add`, `list`, `done` и `tags` продолжают работать, включая существующие параметры и сообщения об ошибках.
- K2. Приоритет новой задачи без явного выбора остаётся `normal`; `add --priority` сохраняет выбранное значение.
- K3. `list` показывает приоритет, сортирует `high`, `normal`, `low` и сохраняет порядок файла внутри одного приоритета.
- K4. Номера в `list` остаются позициями в файле; `done <номер>` изменяет задачу с этим номером.
- K5. Фильтры `--done`, `--open`, `--tag`, `--priority` продолжают сочетаться, не меняя постоянных номеров.
- K6. Старые `tasks.json` без версии или приоритета продолжают читаться; существующие записи не теряются.
- K7. Пустой список успешен и ничего не печатает; ошибки идут в stderr с ненулевым кодом.
- K8. Инструмент работает без установки зависимостей из сети.
- N1. Новая команда не редактирует текст, теги или признак выполнения и не добавляет сроки, проекты или цветной вывод.
