# Requirements: Приоритеты задач

## Validated

- [x] **PRIO-01**: Новая задача без явно указанного приоритета получает `normal`; допустимы только `high`, `normal`, `low`.
- [x] **PRIO-02**: `add --priority` сохраняет выбранный приоритет вместе с текстом и тегами.
- [x] **PRIO-03**: `list` показывает метку приоритета после отметки выполнения и сортирует `high`, `normal`, `low`, сохраняя порядок файла внутри уровня.
- [x] **PRIO-04**: `list --priority` сочетается с фильтрами `--done`, `--open` и `--tag`.
- [x] **COMP-01**: Постоянный номер соответствует позиции в файле; `done` и `tags` продолжают работать.
- [x] **COMP-02**: `tasks.json` версии 2 хранит `text`, `done`, `tags`, `priority`; старые записи без версии или приоритета читаются без потери данных.
- [x] **COMP-03**: Пустой список успешен и пуст; ошибки пишутся в stderr с ненулевым кодом; установка зависимостей из сети не нужна.

## Out of Scope

- Смена приоритета существующей задачи, сроки, проекты и цветной вывод.
