# Приоритеты задач в `tasks`

## What This Is

`./tasks` — локальная Python CLI со списком в `tasks.json` текущего каталога. Приоритет задачи — `high`, `normal` или `low`.

## Core Value

Пользователь видит важные задачи первыми, не теряя постоянные номера, теги и старые записи.

## Requirements

### Validated

- ✓ `add <текст> [--tag <тег>] [--priority <high|normal|low>]` сохраняет задачу; без выбора приоритет `normal`.
- ✓ `list [--done|--open] [--tag <тег>] [--priority <high|normal|low>]` сочетает фильтры и сортирует `high`, `normal`, `low`, сохраняя порядок файла внутри группы.
- ✓ Строка списка показывает постоянный номер, отметку выполнения, `[priority]` перед текстом и теги.
- ✓ `done <номер>` меняет задачу по позиции в файле; `tags` считает задачи по тегам.
- ✓ Версия файла — 2; запись содержит `text`, `done`, `tags`, `priority`. Старые файлы без версии или приоритета читаются, отсутствующий приоритет считается `normal`.
- ✓ Пустой список завершается успешно без вывода; ошибки дают ненулевой код и идут в stderr.

### Out of Scope

- Изменение приоритета уже созданной задачи, её текста или тегов.
- Сроки, проекты и цветной вывод.

## Constraints

- Не переставлять записи в `tasks.json`; номер всегда соответствует позиции в файле.
- Использовать только стандартную библиотеку Python без сетевых зависимостей.
