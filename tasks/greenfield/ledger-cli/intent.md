# Учёт личных расходов

Нужен консольный инструмент, которым я веду учёт своих трат и доходов. Сейчас
я держу их в заметках, и мне надоело считать итоги руками.

## Как я хочу им пользоваться

Запускаю из каталога проекта исполняемый файл `./ledger`. Данные он хранит в
файле `ledger.json` в текущем рабочем каталоге и создаёт его при первой записи.

Команды, которые мне нужны:

- `./ledger add <сумма> <категория> [описание]` — записать операцию.
  Положительная сумма — доход, отрицательная — расход. Сумма в рублях, до двух
  знаков после запятой. Категория — одно слово. Описание необязательно и может
  состоять из нескольких слов.
- `./ledger list [--category <категория>]` — вывести операции, по одной в
  строке, в порядке добавления. Формат строки:
  `<номер>  <сумма>  <категория>  <описание>`, поля разделены двумя пробелами,
  описание может быть пустым. Номер — порядковый, начиная с 1.
- `./ledger balance [--category <категория>]` — вывести одну строку с итогом:
  `<сумма>`. Итог — сумма всех операций, с учётом знака.

Суммы везде печатаются с двумя знаками после запятой и точкой в качестве
разделителя: `-1250.00`, `3000.50`.

При ошибке — неизвестная команда, недостающий или неразборчивый аргумент,
испорченный файл данных — инструмент печатает понятное сообщение в поток
ошибок и завершается с ненулевым кодом. При успехе код возврата — ноль.

## Что мне важно

Инструмент должен работать сразу после `git clone`, без установки зависимостей
из сети. Язык реализации выбери сам, исходя из этого требования.

Меня не интересует ни графический интерфейс, ни синхронизация, ни несколько
пользователей, ни валюты кроме рубля.
